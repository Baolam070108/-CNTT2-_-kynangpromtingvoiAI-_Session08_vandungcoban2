*Bước 1: Phân tích lỗi**

Prompt ban đầu sử dụng hai kiểu biến khác nhau là `[language]` và `{audience}`. Điều này khiến AI khó nhận diện và thay thế thông tin tự động, gây thiếu thống nhất.

*Bước 2: Đồng bộ biến số**

Prompt sau khi sửa:

Hãy viết một bài chia sẻ về Quản trị Prompt & System Instructions bằng ngôn ngữ [NGÔN_NGỮ]. Dành cho đối tượng [ĐỐI_TƯỢNG].

*Bước 3: Chạy thử**

- [NGÔN_NGỮ] = Tiếng Việt.
- [ĐỐI_TƯỢNG] = Sinh viên Công nghệ thông tin.

**Kết quả chạy thử:**

Quản trị Prompt là cách xây dựng câu lệnh để AI hiểu và thực hiện đúng yêu cầu. System Instructions là những chỉ dẫn giúp AI biết vai trò, nhiệm vụ và cách hoạt động.

Ví dụ: Yêu cầu AI làm trợ giảng lập trình và giải thích code C một cách dễ hiểu.
